What is OrbitGuard?

OrbitGuard is an offline visual checklist system designed to monitor laboratory experiments through a camera and verify whether experiment steps are performed in the correct order.

It tracks objects in predefined rack-anchored zones and provides real-time guidance when an expected action is detected.

How It Works

01. Detect

The camera feed is analyzed to detect the red and yellow experiment boxes.

02. Track

Objects are tracked according to their position within rack, Tray A and Tray B zones.

03. Verify

OrbitGuard checks whether the detected actions follow the predefined experiment sequence.

Key Features

Live Detection

Tracks experiment objects in real time.

Step Guidance

Shows the current and next expected experiment step.

Offline & Private

Designed to operate locally without requiring cloud processing.

Experiment Sequence

OrbitGuard currently demonstrates a two-box sorting experiment:

  1. Load the red and yellow boxes into the rack.
  2. Pick up the red box.
  3. Place the red box in Tray A.
  4. Pick up the yellow box.
  5. Place the yellow box in Tray B.
  6. Verify that both boxes are stable and the workspace is clear.
